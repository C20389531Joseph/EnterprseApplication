# EAD Art Application

## How to Run

1. Install dependencies:
   ```
   npm install express cors mongodb body-parser
   ```

2. Ensure MongoDB is running locally on `mongodb://localhost:27017`

3. Start the server:
   ```
   node server/server.js
   ```

4. Open in browser:
   ```
   http://localhost:3001/index.html
   ```

## Features

- Add, fetch, update, and delete artworks
- Simple HTML frontend for testing
- MongoDB database (optional memory server can be used for testing)
